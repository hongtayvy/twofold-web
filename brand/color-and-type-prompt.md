You are working on TwoFold, a personal finance app for couples. Follow this colour and type system exactly. If a request would break a rule, say which one and offer the closest option that follows it.

COLOUR
Use only these colours. No additional hues, no other shades.

- Paper `#FAFAF7`: page background. Never pure white.
- Ink `#18211C`: text and dark surfaces. Never pure black.
- Mute `#5C6862`: secondary text.
- Line `#E5E9E4`: hairlines, card borders, secondary button borders.
- Field `#879388`: form input and dropdown borders.
- Overlap `#6E7B4A`: shared goals and totals, where the two partners' colours meet.
- Jade-400 `#7CBC9E`: partner two (Jon).
- Jade-600 `#3B8168`: the only action colour. Every button and link.
- Jade-700 `#2E6552`: hover state for actions; success text.
- Apricot-400 `#E3A377`: partner one (Maya).
- Apricot-700 `#88512C`: error text and error borders.

Light tints: jade-50 `#EFF7F2` (success background), jade-100 `#DEEFE5`, jade-200 `#C2E2D0`; apricot-50 `#FDF4EC` (error background), apricot-100 `#FAE7D6`, apricot-200 `#F3CFB1`.

Rules:
1. Apricot is Maya, jade is Jon, overlap is shared. Use each partner's colour wherever that partner's data appears.
2. Always pair a partner colour with the partner's name. Both are pastels, so the colour alone is too faint to carry meaning.
3. Jade-600 is the only colour an interactive element can be; hover is jade-700. Apricot never goes on a button.
4. Errors use apricot-700 on apricot-50, always with an icon and clear words.
5. Light theme only.

TYPE
One typeface: Inter, weights 300, 400, 500, 600 and 700, for headlines, subheadings, body, UI, labels and supporting text alike.

Rules:
1. All money figures, totals and other numbers use Inter with tabular numerals (`font-variant-numeric: tabular-nums`) so decimals line up.
2. Build hierarchy with weight and size together: headlines 600 to 700, body 400, labels 500.
3. The wordmark is "TwoFold": one word, capital T and capital F, set in Inter.
